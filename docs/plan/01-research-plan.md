# Research plan (no reference hardware)

Purpose: produce the calibration data the DSP model is fitted to, and close the remaining behaviour gaps, using the Service Notes, the schematic, offline circuit simulation and published measurements. A bench protocol is kept at the end for anyone who later has a unit.

Deliverables:

- `docs/spec/behaviour.md`: frozen behaviour specification, every control and mode, with manual page references (source: research/05 plus research/02 where not contradicted).
- `docs/spec/circuit/`: one page per block with a redrawn schematic extract (own drawing), component table and derived transfer function.
- `tools/sim/`: ngspice (or ACME.jl) netlists per block and their reference outputs (CSV), regenerated by script.
- `calibration/juno60.json`: every constant and table the DSP reads, with a `source` field per entry (service-notes, schematic, simulation, published-measurement, plugin-derived, assumed).
- `docs/calibration-report.md`: plots and the uncertainty list.

## 1. Document track

### 1.1 Behaviour spec freeze (week 1)
Write `docs/spec/behaviour.md` from research/05, resolving each remaining ambiguity with a stated choice:
- LFO triangle phase on trigger: free-running oscillator, only the delay envelope restarts (the circuit is a free-running integrator with a separate delay VCA; the schematic shows no reset path).
- LFO TRIG in MANUAL gates all LFO destinations including PWM.
- Voice stealing: rotary assignment, steal the oldest-gated voice regardless of release state (SN wording).
- Key transpose: upward 0 to 11 semitones, top C = +12.
- Power-up display: "- -" (manual mode), consistent with CPU reset behaviour after tape operations.
- MANUAL mode display: "- -".
- WRITE with protect on: "Pr".

### 1.2 Schematic extraction (weeks 1 to 2)
From the Service Notes pages 5, 7, 9, 11, 13 redraw and tabulate:
- CPU board p.9: one DCO channel (IC16 integrator, C7, TR5, C6/R34, R36 1 %), the KCV DAC and anti-log amp (IC51 to 53, TR56, IC38/39), KCV S/H, PWM comparator and S/H (IC41/43/45 with -6.5 V and -0.5 V endpoints), the IR3109 input network (68 k / 560 R / 240 pF x4), BA662 resonance path with its input-side Q-compensation resistors, BA662 VCA with R42 load, IR3R01 timing network (47 nF, VR6), the sub flip-flop and TR4 level. The page is a scan at limited resolution; where a value cannot be read with certainty, mark it and fall back to the Juno-6 reading or the SH-101/Jupiter-8 standard value with a note.
- Chorus board p.11: HPF (IC5 cap set and resistor network), uPC1252H2 level VCA, input buffer, both Sallen-Key chains, BBD clock oscillators, mute, summers.
- Panel Board A p.5: LFO (IC11/12/14/15) and delay, PWM mode selector and depth VCA, noise generator TR5 and its filtering, VCF CV mix (IC20 to 24) with the depth VCAs and polarity switch.
- Panel Board B p.7: chorus LFO (IC1 to 3) including the I / II / I+II switching network and the factory LFO amplitude modification.
- Bender board p.13: bender CV scaling, octave transpose diode logic.
- Jack board p.10: output level network, VCF pedal 3 V offset.

### 1.3 Offline reference simulations (weeks 2 to 3)
ngspice netlists with OTA macro-models (LM13700-style for the IR3109 cells and BA662) and standard op-amp models:
- IR3109 cascade + BA662 feedback: magnitude response on a 16 x 8 cutoff x resonance grid; self-oscillation frequency vs control current; harmonic series at three drive levels; passband loss vs resonance. Anchor the control-current law to the Service Notes targets (248 Hz at FREQ 3; +2 octaves at C6; LFO sweep 40 Hz to 5 kHz; ENV peak 30 kHz).
- DCO integrator with reset: saw shape, flyback duration, DC offset, at 65 Hz, 442 Hz, 2 kHz and 4.2 kHz.
- HPF: four positions.
- Chorus pre and post filter chains: poles, -3 dB points (resolves the 6.5 vs 9.7 kHz disagreement in research/01).
- BBD clock oscillator: clock frequency vs LFO voltage (affine period vs hyperbolic), to set the delay sweep law.
- Chorus LFO: period and amplitude per mode from the Panel Board B network.
- LFO delay circuit: hold-then-fade shape vs DELAY slider, to confirm the published hold/fade table.

### 1.4 Published measurements (week 3)
Integrate pendragon-andyh's envelope, LFO, chorus and HPF tables and Holters-Parker's BBD gain into the calibration file, each tagged `published-measurement`. Where the simulation and a measurement disagree by more than the stated tolerance, record both and prefer the measurement for time-domain behaviour (envelope, LFO, chorus rates) and the simulation for frequency-domain behaviour (filter curves).

### 1.5 Slider tapers (week 3)
The hardware reads every slider as 8 bits and the panel CPU regenerates a CV; the mapping from CV to effect is in the analogue circuit. Sources, in order: Service Notes endpoints (both ends of every slider are pinned by the adjustment procedure or the spec), simulation of the CV network, published measurements at 0 / 2.5 / 5 / 7.5 / 10, and plugin-derived curves only to choose between candidate shapes. Each taper is stored as a table in the calibration file.

### 1.6 Prior art code review (week 2, parallel)
Read KR-106's `docs/DSP_ARCHITECTURE.md`, Hera's chorus and envelope code, jpcima's `bbd-delay-experimental`, and pendragon-andyh's analysis notes, and record which design choices are adopted and which are not, with reasons, in `docs/research/07-prior-art-review.md`. Nothing is copied without licence compatibility (all GPLv3 or more permissive).

## 2. Calibration file

  "dco": { "saw_vpp": 12.0, "pwm_cv_50pct": -6.5, "pwm_cv_97pct": -0.5, "flyback_us": {...} },

  "env": { "attack_s": [...11 points...], "decay_s": [...], "release_s": [...], "sustain_curve": [...] },

## 3. Bench protocol (kept for the future)

If a serviced Juno-60 becomes available, the full capture protocol (DCO per note, VCF grid, envelope and LFO tables, chorus per mode, HPF, firmware timing) is in `docs/research/08-bench-protocol.md`, moved there from the first version of this plan. It produces a replacement calibration file without code changes.

## 4. Panel reference material

- Photographs: a straight-on, high-resolution set is needed to draw the vector panel. Candidate sources are being evaluated (Audiofanzine gallery, Wikimedia Commons). Used for measurement only; never committed.
- Dimensions: 1060 x 378 x 113 mm overall (OM p.33). Slider travel and spacing are derived from the photographs against that width. The Service Notes parts list gives slider pot models (EVA-TOHC14 series, a standard Panasonic 60 mm travel family) which fixes the travel length if the photographs are ambiguous.
- Lettering: panel labels transcribed from OM p.5, 12 to 22 and the Service Notes p.1 panel figure.

## 5. Performance layer research (phase 7 inputs)

- Polyend Play and Tracker chord and scale mode behaviour: pad-to-degree mapping, chord types per degree, voicing options, how "both modes" interact. Source: Polyend manuals (user to supply if blocked).
- Novation Circuit Rhythm: pad note numbers and channel in controller use, velocity, LED control from the host. Source: Novation user guide and any programmer's reference (user to supply if blocked). If the Circuit Rhythm cannot accept LED control, the fallback list is Launchpad Mini MK3 / X / Pro MK3 programmer mode and Ableton Move in controller mode.
- Mac keyboard: JUCE key events in the standalone app; key repeat suppression; n-key rollover limits of typical Mac keyboards (usually 6 simultaneous keys over USB HID, which happens to match the Juno's six voices).
