# jnsynth

Open-source, component-modelled recreation of the Roland Juno-60 (with a planned Juno-106 mode) as a native macOS AU / VST3 / AAX plugin and standalone app.

Status: research and planning. No code yet.

- `docs/plan/00-overview.md`: scope, state of knowledge, decisions awaiting the owner
- `docs/plan/01-research-plan.md`: remaining research, bench measurement protocol, source inputs needed
- `docs/plan/02-development-plan.md`: stack, architecture, block specs, phases, testing
- `docs/research/`: compiled research notes (circuit analysis, panel behaviour spec, 60 vs 106 and prior art, engineering stack)
